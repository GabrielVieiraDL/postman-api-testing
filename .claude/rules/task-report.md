# Rule: Relatório obrigatório de task

Ao final de cada implementação, criar documento em `docs/tasks/YYYY-MM-DD-[feature].md` registrando:
1. Resumo da implementação e arquivos alterados
2. Testes executados e status (Newman/Postman)
3. Contratos de API validados
4. Riscos remanescentes e decisões tomadas
